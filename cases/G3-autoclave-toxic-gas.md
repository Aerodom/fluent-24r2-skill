# G3 · 高压釜易燃易爆和有毒有害气体泄漏

> **一句话画像**：10×10×10 m 房间内高压釜泄漏 → 有毒气体（SO₂）在**呼吸高度**扩散 → 危险区随时间扩大（十秒级）。
> **状态**：★ 实测跑通｜**最后实测**：2026-09（2262 步 = 11.31 s）｜**本案例是 C 类（组分输运）的样板，也是"长跑 + 栅格交付"的样板。**

## 4 材料与组分

| 项 | 值 |
|---|---|
| 混合物 | **`{so2, air}`** —— **`air` 作差减组分（last_species）** |
| 变量 | `molef-so2`（摩尔分数）、`massf-so2`（质量分数） |

⚠️ **这是本案例最重要的一条**：若写成 `{so2, o2, n2}` 且 `last_species = n2`，`standard_initialize()` 会把 **N₂ 填 1** ⇒ **整个域被初始化成纯氮气**（实测 106560/107222 单元），O₂ 只能靠出口回流渗入，环境密度 1.165 vs 空气 1.225（差 5%）⇒ 浮力参比失真。
用 `air` 作差减组分则：初始化天然是空气、少一条组分方程、且与环境口径一致。
⚠️ `air` 是 Fluent **默认**材料，**别**再 `copy_by_name('air')`（会得到 `air-1`）。

## 7 初始化与 patch

1. Standard Initialization：表压 0、298 K、`so2` 质量分数 0。
2. **核验 `last_species`**：初始化后抽几个单元看 `massf-n2`/`massf-o2` 是否合理（不该是 1）。
3. patch 泄漏源（若用 patch 方式）。

## 8 推进策略

- `dt = 5e-3`，2262 步 = 11.31 s。
- autosave `data-frequency 200`；本案例曾用**分段续算 + 看门狗**跑完 2262 步（每段 400~700 步）。
- 长跑判活看 `.trn`（`Flow time = X, time step = N`），不要看调度日志的刷新（8 KB 块缓冲可达 3 min 不刷盘）。

## 10 后处理与交付

**数据溯源链（可字节级复现，评审必查）**：

```text
FLTG-1-*.dat.h5（原始）
  → fix/G3_fix-*-*.dat.h5（修初始场后重跑，-5-02200 收尾）
  → so2_*.xyz × 13（extract_all.jou，/file/export/ascii）
  → G3_grid_100x100.csv（rasterize_so2.py → make_grid_csv.py）
```

**自检三招**：
1. 表头必须是 `cellnumber x-coordinate y-coordinate z-coordinate molef-so2`；
2. **数据行数 = 网格单元数（74796）**；
3. 重跑栅格化到临时目录，`diff -q` **逐字节一致**。

**交付文件**（形态 C，长表**故意无表头**）：
```
wide:  time, R_*, Y_*        （100×100 宽表，20 001 列）
long:  time, cell, red, yellow（无表头）
summary: time_s, red_cells, yellow_cells, red_area_frac, yellow_area_frac
```

**三个强制口径**：
- 格号 **`k = i*NZ + j`**（i ↔ X 房间宽，j ↔ Z 房间深）；脚本、长表转换、下游解析**三处必须同一个定义**；
- 最近邻用**逐点 argmin**，**禁 `scipy.griddata`**（偏小 20%）；
- 块占位比 ≥ 0.5 判该格危险；
- 二值掩膜**禁线性插值**；`NX ≥ 50` 时启用 `3×3 闭运算 + 3×3 中值滤波×2`（碎块 38→7，面积 +7%）。

## 11 已知坑（本案例专属）

| 现象 | 根因 | 处理 |
|---|---|---|
| **"环境大气"变纯氮气**（106560/107222 单元） | `last_species`（差减组分）被填 1，混合物写成了 `{so2,o2,n2}` | 改 `{so2, air}`，`air` 作差减组分；别再拷 air |
| 栅格红区碎成马赛克、四角误标红 | 1923 个呼吸层单元铺到 100×100，最近邻必然噪 | 闭运算 + 中值滤波（NX≥50 自动开），并把面积 +7% 写进误差说明 |
| 危险区面积与 post 基准差 20% | 用了 `scipy griddata nearest`（凸包外推） | 逐点 argmin |
| 面积暴涨一倍 | 二值掩膜用了线性插值 | 二值禁线性 |
| 长跑"卡住"不动 | 看的是调度日志（块缓冲） | 看 `.trn` 的 mtime |
| 长跑产物停在某 checkpoint、调度日志断半句 | 进程随会话结束被整棵杀掉 | 外部周期拉起（任务计划 + PID 锁幂等），见 `../../references/auto-resume-and-guard.md` §9 |
| 后处理某步 rc=2 导致整链无限重试 | 脚本 `nargs="?"` 只收单场景却被传多个 | 改 `nargs="*"` + 逐场景 try/except，接链后真跑一次 |

## 13 复用与差异

- **可以直接照抄的**：`{so2, air}` 混合物配方、重力开、呼吸层切片口径、阈值与栅格化全链路、离线 h5 取数。
- **必须改的**：房间尺寸、泄漏口位置、组分种类（As₂O₃ 是**颗粒态**，需 DPM/分相，**不要沿用单组分假设**）。
- **不能照抄的**：`scipy.griddata`、线性掩膜、无表头以外的列序（下游按文件名 + 列布局解析，改了就断）。
