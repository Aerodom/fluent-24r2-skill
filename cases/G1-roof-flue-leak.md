# G1 · 炉顶含 SO₂、As₂O₃ 等烟气泄漏

> **一句话画像**：炉顶烟道/炉口**持续**逸出含 SO₂ 与 As₂O₃ 的烟气 → 重气下沉 + 湍流扩散 → 呼吸层浓度累积（十秒~分钟级）。
> **状态**：未实测｜与 [G3](G3-autoclave-toxic-gas.md) 同属 C 类，但**是"持续源"且带颗粒相**，两处必须改。

## 1 选型卡

| 项 | 取值 | 与 G3 的差异 |
|---|---|---|
| 求解器 | 压力基 + Species Transport（无反应） | 同 |
| 湍流 | Realizable k-ε | 同 |
| 能量 | **建议开**（烟气温度高于环境，热浮升与重气下沉相互竞争） | G3 没开 |
| 重力 | **开**，Y = −9.81 | 同 |
| 源类型 | **质量流入口（持续源）** | G3 用瞬时 patch |
| 颗粒相 | **As₂O₃ 是颗粒态 ⇒ DPM 或多相** | G3 单组分假设 |
| 时间步 | 5e-3 ~ 1e-2 s | 同量级 |
| 验收量 | 呼吸层 SO₂ 浓度时序、As 沉降/悬浮分布、危险区 |

## 2 几何与计算域

- 车间 + 炉体，源在**炉顶/烟道口**（位置按设备图）。
- 竖直轴 Y；呼吸层 `y = 1.5 ± 0.1 m`（口径同 G3，便于跨案例比较）。

## 3 网格

- 源口附近加密（持续射流/浮羽的卷吸区）。
- 呼吸层单元数决定栅格化上限（参考 G3：1923 单元 ⇒ 100×100 必须有去噪）。
- 若加 DPM：**颗粒轨迹要求网格尺度 ≫ 颗粒直径**，且需足够长的停留路径。

## 4 材料与组分

| 项 | 值 |
|---|---|
| 气相混合物 | **`{so2, air}`**（`air` 作差减组分）—— 与 G3 完全一致 |
| 颗粒相（As₂O₃） | DPM 惰性颗粒，给粒径分布、密度、质量流率 |

⚠️ **不要直接沿用 G3 的单组分假设**：As₂O₃ 以颗粒/气溶胶存在，输运机制（沉降、惯性撞击）与气相扩散不同。

## 5 模型与求解设置

- Species Transport（volumetric reactions = no）
- 若开 DPM：`Discrete Phase` 打开，勾选与连续相耦合（双向耦合），颗粒边界条件（trap/reflect/escape）要逐面设
- Realizable k-ε；能量方程按需开

## 6 边界条件

| zone | 类型 | 值 |
|---|---|---|
| 炉顶源 | **mass-flow-inlet**，给 SO₂ 质量分数与总质量流 | 持续源 |
| 厂房开口 / 门窗 | pressure-outlet | 表压 0 |
| 壁面 | wall | 颗粒在此按 reflect/trap 设 |
| 地面 | wall | **As₂O₃ 沉降的统计面** |

## 7 初始化与 patch

1. 标准初始化：环境空气（`{so2, air}` 的 so2 = 0）。
2. **核验差减组分**（同 G3 的 `last_species` 陷阱）。
3. 若有 DPM：先跑无颗粒的纯气相收敛，再加颗粒（避免一上来就被颗粒源顶发散）。

## 8 推进策略

- 持续源 ⇒ 总时长要足够长到呼吸层浓度达到准稳态（判据：`dC/dt` 在最近 20% 时长内 < 5%）。
- 建议监控"呼吸层平均/最大浓度"而不是单点，避免局部脉动误判稳态。

## 9 监控与验收判据

| 判据 | 标准 | 来源 |
|---|---|---|
| 呼吸层浓度准稳态 | 最近 20% 时长 `dC/dt` < 5% | 自定 |
| 质量守恒 | 入口 SO₂ 质量流 = 出口 + 域内累积率 | 自检 |
| 危险区面积 | 阈值同 G3（100 ppm / 20 ppm），口径写明 | 职业卫生判据 |

## 10 后处理与交付

- 与 G3 完全对齐的文件集合与列序（宽表 `time,R_*,Y_*`、长表 `time,cell,red,yellow`、摘要 5 列），**下游零改动**。
- 额外交付 As₂O₃ 地面沉降通量表（若开 DPM）。

## 11 已知坑（本案例专属）

| 现象 | 根因 | 处理 |
|---|---|---|
| 浓度一直涨不到稳态 | 源是持续的，但总时长不够 | 按"dC/dt < 5%"判稳，不要拍拍脑袋定时长 |
| 烟气"飘走了"不下沉 | 忘了开重力，或热浮升压过重气效应 | 开重力 + 开能量，二者必须一起考虑 |
| 颗粒全部撞在入口附近 | DPM 与连续相未耦合 / 网格太粗 | 双向耦合 + 源口加密 |
| 组分列名找不到 | 变量名大小写敏感（`molef-so2`） | 按实际场名取，先 list 再选 |

## 13 复用与差异

- **可以直接照抄的**：`{so2, air}` 混合物、重力、阈值与栅格化全链路、交付文件集合。
- **必须改的**：源类型（持续 vs 瞬时）、是否开能量、是否加 DPM、源位置。
- **不能照抄的**：G3 的瞬时 patch 方案；G3 的单组分假设。
