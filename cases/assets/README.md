# cases/assets/ —— 案例素材目录

这里放**不适合塞进卡片正文**的东西：起作用的 journal、长表格、网格参数、
场数据导出的中间文件、给某个案例专用的校验脚本。

## 约定

```
cases/assets/
├── <ID>/                  # 目录名必须等于卡片 ID（L4、B2、G3 …）
│   ├── mesh.jou
│   ├── setup.jou
│   └── probes.csv
└── README.md              # 本文件
```

1. **目录名 = 卡片 ID**。`check_cases.py` 会校验卡片里出现的 `assets/<ID>/...`
   引用是否真实存在；目录名与 ID 不一致会让校验报错。
2. 卡片里用**相对路径**引用，如 `assets/L4/mesh.jou`（相对 `cases/` 解析）。
3. **不放大文件**：单个文件超过约 5 MB 就不要提交（`.dat.h5`、`.msh.h5`
   一律不进仓库），在卡片里写"如何重新生成"比提交文件更有价值。
4. 素材里同样**不能有**本机绝对路径、真实公司名、内部项目编号 ——
   `scripts/audit_sensitive.py` 会扫这个目录。

## 为什么默认是空的

大部分卡片的信息量已经够复现（journal 片段直接写在卡片 §5/§6 里）。
素材目录只在"卡片正文放不下"时才用 —— 空目录不代表缺失，而是
**默认不往仓库里塞二进制**。
