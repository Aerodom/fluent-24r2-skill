# L4 · 高压釜酸碱溶液泄漏

> **一句话画像**：10×10×5 m 厂房内高压釜 Ø30 mm 孔破裂 → 酸液以 40 kg/s 泄出 → 地面液池铺展（秒级）。
> **状态**：★ 实测跑通｜**最后实测**：2026-09｜**可作 L1–L3 的优选起点**（单相物性、无辐射/凝固，配置最干净）。

## 1 选型卡

| 项 | 取值 |
|---|---|
| 物理类型 | 高密度比自由液面铺展（B 类） |
| 求解器 | 压力基 |
| 时间 | 瞬态 |
| 多相 | VOF：主相 air / **次相 acid**（phase-2） |
| 湍流 | 本案例按层流跑通（湍流对液池铺展主导期影响小） |
| 能量 | 常温泄漏，可不做能量耦合 |
| 辐射 | 无 |
| 重力 | **沿 Y = −9.81 m/s²** ← **不是默认 Z，极容易错** |
| 时间步 | 两阶段：**1e-4 s × 5000 步 → 2e-3 s × 4750 步**（实际算例均按 2e-3 s 出结果） |
| 网格量级 | 待补（Watertight Geometry 工作流） |
| 验收量 | 液池体积时序（峰值、终值）、地面铺展范围 |

## 2 几何与计算域

| 项 | 值 |
|---|---|
| 厂房 | **10 (X) × 10 (Z) × 5 (Y) m** |
| 竖直轴 | **Y** |
| 泄漏孔 | **Ø30 mm**，位于高压釜侧壁 |
| 泄漏源 | **40 kg/s** 质量流 |

## 3 网格

| 项 | 值 |
|---|---|
| 路线 | Fluent Meshing **Watertight Geometry** 工作流（见 `../../references/meshing-routes.md` §2） |
| 单元数 | 待补 |
| 加密 | 泄漏孔附近 + 地面液池铺展区 |
| 检查 | `/mesh/check` 最小体积 > 0；孔口至少 3~4 格跨 |

## 4 材料与相

| 相 | 密度 | 粘度 | 备注 |
|---|---|---|---|
| 主相 air | 1.225 | 1.7894e-5 | 默认 |
| 次相 acid | **1200** | **0.002** | 酸碱溶液等效物性 |

## 5 模型与求解设置

- VOF **隐式**（`formulation implicit`，且**先于**时间格式设置）
- 压力-速度耦合：**PISO**
- 梯度：Green-Gauss Node-Based
- 压力：**PRESTO!**
- 体积分数：**Compressive**
- 动量：二阶迎风
- **Implicit Body Force：开**
- 表面张力：关（Bo ≫ 1）
- **禁 `geo-reconstruct`**（隐式 VOF 下会崩进程）

## 6 边界条件

| zone | 类型 | 值 |
|---|---|---|
| 泄漏孔 | mass-flow-inlet | **40 kg/s** |
| 厂房侧壁 | wall（**不要从 y=0 一路开 pressure-outlet**） | — |
| 屋顶/通风口 | pressure-outlet | 表压 0 |
| 地面 | wall 无滑移 | — |

## 7 初始化与 patch

1. Standard Initialization：表压 0、T 298 K、速度 0。
2. 无液块 patch（泄漏由入口驱动）。
3. **t=0 核验**：域内总体积/总质量与手算一致。

## 8 推进策略

- **两阶段步长**：先 1e-4 × 5000 步打通初始射流（避免开局 Courant 爆掉），再切 2e-3 × 4750 步。
- ⚠️ `/solve/set/time-step` 必须在切到瞬态**之后**执行才生效。
- autosave 间隔按出图/交付帧率定（本案例交付 1725 个时间点）。

## 9 监控与验收判据

| 判据 | 基线 | 说明 |
|---|---|---|
| 酸液体积峰值 | **8.195 m³ @ t = 0.31 s** | 体积分 `∫α₂dV` |
| 终值 | **6.444 m³** | 泄漏停止后回落（液池摊薄/流出） |
| 液池范围 | 不超出厂房地面 | 目视 + 面积统计 |
| 曲线形态 | 先升后平/缓降，无振荡 | 有振荡先查界面格式与 Courant |

## 10 后处理与交付

- **形态 A（两列时序 CSV）**：`1725` 个时间点，**两列、无表头**（`time_s, volume_m3`），下游直接按列解析。
- 取数优先离线 h5（`∫α₂dV`），口径写进文件名：`volume_acid_<case>.csv`。
- 体积分用 `report_type="volume-integral"` 或离线 `Σ V_cell·α₂`；两者应逐位对齐。

## 11 已知坑（本案例专属）

| 现象 | 根因 | 处理 |
|---|---|---|
| 液体往"上"流 / 沿错误方向堆 | **重力轴向没改**（Fluent 默认沿 Z） | 显式设 `Y = −9.81`，并在交付文档写明轴向 |
| 开局 Courant 爆掉、液体瞬间乱溅 | 直接上 2e-3 s 起步 | 用两阶段步长（1e-4 → 2e-3） |
| 液池体积曲线台阶状跳变 | 交付取了 autosave 帧而非每步监控 | 体积时序用 report-file 每步写，不要用 dat 帧反推 |
| 首步长时间不出 `Flow time` | 内存不足（不是发散） | 查提交内存，清残留 `cx2420/fl2420/fl_mpi2420` |

## 13 复用与差异

- **可以直接照抄的**：整套 VOF 配方、两阶段步长、边界拓扑（wall + 屋顶泄压）、体积时序交付格式。
- **必须改的**：泄漏孔径与质量流、次相物性、厂房尺寸、是否加能量方程。
- **不能照抄的**：**熔体类案例（L1–L3）不能只改密度**：熔体要高粘度 + 温度 + 可能凝固 + 辐射，且密度比更高会病态（见 L1 §11）。
