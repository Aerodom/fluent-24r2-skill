# 地面泼溅**轮廓时序**提取（→ 下游多边形/栅格）

> 案例来源：L1（熔体泄漏 CFD）。脚本：`<PROJ>/PL/v2/work/export_footprint_contours.py`
> 产出示例：`<PROJ>/PL/v2/results/L1/L1_splash_contours.json` + `L1_轮廓数据说明.md`

下游要"能看出泼溅面积在长"的**几何**，而 `monitors_<S>.csv` 只有 `∮αdA`、`A(α>ε)` 这些**标量**。
本节解决"标量 → 每 0.5 s 一帧的闭合轮廓多边形"这一段，以及路上踩过的四个坑。

## 1. 帧率天然对齐：先看存档节奏

`time step = 0.005 s`、`autosave every 100 steps` ⇒ **存档就是 0.5 s 一帧**，正好对上
"每 0.5 s 一份时序数据"的需求，**不需要重跑、也不需要插值**。
开工前先算这一步：`帧间隔 = 步长 × 存档间隔`，对不上再谈插值或重跑。

同一场景里 `PL_<S>_final.dat.h5` 与 `PL_<S>_step600.dat.h5` **内容相同** ⇒
按 `t_s` 去重（保留 `final`），否则会得到两条一样的曲线。

## 2. 面量 → 节点量（`tricontour` 的硬前提）

`alpha2` 是**逐面**量，`matplotlib.tricontour` 只吃**逐节点**量。转法：相邻面算术平均。

```python
def node_alpha(mesh, tri, alpha):      # tri: (nface,3) 全局节点索引(0-based)
    n = mesh.coords.shape[0]
    idx = tri.ravel()
    cnt = np.bincount(idx, minlength=n)
    s = np.bincount(idx, weights=np.repeat(alpha, 3), minlength=n)
    return np.where(cnt > 0, s / np.maximum(cnt, 1), 0.0)
```

三角剖分必须用**全局节点坐标**：
`Triangulation(mesh.coords[:,0], mesh.coords[:,2], tri)`，`tri` 是该 zone 的全局节点索引。

**副作用**：孤立节点得到非零值 ⇒ 等值线里冒出**面积为 0 的数值小岛**
（实测每帧十几个 5~7 点的环）。必须过滤，见 §4。

## 3. ⚠️ 坑 1：炉体底面是**自由边界**，等值线会被截断成开口链

地面在原点常有一个几何洞（本例 φ3.2 m 炉体底面，r = 1.598 m，**那里没有面**）。
破口若就在炉壁脚外，外缘等值线会撞上这个自由边界 ⇒ `tricontour` 返回**开口链**
（实测 t=3.0 s 开口 2.30 m，两端点 r 都 ≈ 1.60 m）。

拉直线闭合会**切掉一块炉底**（弦长 2.30 m）⇒ 必须**沿炉壁圆弧补点**。

**方向怎么判**：圆弧有两条，取"中点向炉外探一格（≈1 个地面网格）仍是湿的"那条 ——
圆洞边界若属于湿区，紧贴其外侧必然也湿。两侧都不湿时退回短弧并打标记。

```python
if abs(r0 - R) < HOLE_TOL and abs(r1 - R) < HOLE_TOL:      # 两端都在炉壁上
    arc, how = hole_arc(pts[-1], pts[0], interp, eps)       # ⚠️ 环尾 → 环首
    return np.vstack([pts, arc]), how
```

### ⚠️⚠️ 圆弧方向极易写反（本节最贵的一课）

`hole_arc(p0, p1)` 生成的是 **p0 → p1** 方向的点串。它要被接在环尾，所以必须传
**`pts[-1], pts[0]`**。写成 `pts[0], pts[-1]` 会得到一个**蝴蝶结**：

| 指标 | 写反 | 写对 |
|---|---|---|
| 自交（线段相交对） | **3 处** | 0 |
| shoelace 面积 @t=3.0 | 26.64 m² | 25.20 m²（面元法 24.98 ⇒ +0.9%） |
| 与 1 cm 栅格点数法之差 | **−5.4%** | −0.01% |

**发现方式**：把自交点的索引打出来（`(55,59) (55,60) (56,60)`），索引全落在环尾 ⇒
说明问题就在追加的圆弧段，而不是等值线本体。**这个排查套路值得记**。

## 4. ⚠️ 坑 2：噪声环过滤要"绝对 + 相对"双门槛

只有绝对门槛（如 `area > 0.02 m²`）时，会漏掉**面积恰好压线**的 5 点小岛：
实测 L1 t=3.0 s 保留了一个 0.0202 m² 的 5 点环（主环 9.30 m²）⇒ 每帧环数在
1/2/3 之间跳变，动画会闪。

```python
floor_area = max(min_area, rel_min * largest_ring_area)   # 建议 0.05 / 0.01
```

效果：L1 逐帧环数从 1/5/2/1/2 收敛为 1/3/2/1/1；
**必须把 `dropped`（分原因计数）与 `min_ring_area_applied_m2` 写进元数据**，
否则"少了一个环"看起来像算漏。

## 5. 孔洞与外环：用"内点包含计数"判，别用有向面积

嵌套环若不标注，下游（多边形填充）会**重复填充**。判法：

1. 取每环的**内点** —— **不能用重心**（强凹的指状边界，重心可能落在多边形外），
   用水平射线扫描线取交点对中点；
2. 该内点被多少个环包含 → **奇数 ⇒ 孔洞**，偶数 ⇒ 外环；
3. 父环 = 面积最小的那个包含者；
4. 方向约定：**外环逆时针（+）、孔洞顺时针（−）** ⇒ 面积可直接相加，
   `PathPatch` 用 nonzero 规则会自动挖洞。

> 本项目 L1 实测**没有孔洞**：冲击区 `alpha2` 的局部低值（0.017~0.019）只是让
> 轮廓变成**马蹄形**（单条简单闭合曲线、开口朝向炉体），不是洞。
> 叠放图上看到的"内圈"其实是**较早帧的轮廓**被后续大轮廓盖住 —— 别误判成洞。

## 6. ⚠️ 坑 3：面积必须做**独立校核**，否则自交会静默骗你

`shoelace` 对自交多边形给出的是"有符号缠绕面积"，不是几何面积，**错得不明显**。

```python
def raster_area(rings, step=0.01):     # 1 cm 网格 + 奇偶规则，独立于 shoelace
    ...  # 外环 |= contains, 孔洞 ^= contains
```

| 校核项 | 合格线 | L1 实测 |
|---|---|---|
| shoelace vs 1 cm 栅格 | ≤ 1% | ±0.01% |
| 自交对数 | 0 | 0（修圆弧方向后） |
| vs 面元法 `A(α>ε)` | 同量级、t 大时 ≤ 5% | t≥2.0 s ≤ 3.2% |

> `t=1.0 s` 时轮廓法比面元法低 19.5%，但绝对差只有 0.14 m²（斑块仅 0.57 m²）。
> **小面积上不要用相对偏差判对错**。面积口径仍以面元法为准，轮廓面积是几何校核值。

## 7. ★ 主交付必须是"**一行一帧、纯坐标**"的宽表

**长表（`t_s, ring_id, pt_id, x, z`）看着规整，但对下游是最难用的形态**：
任何下游绘图端拿到长表都得先按 `ring_id` 分组、再按 `pt_id` 排序才能拼出一条多边形。
只给长表 + 一份"栅格快照"，下游会直接问"**为什么没有轮廓的纯坐标**"。

所以**必给**一份宽表 `<S>_splash_polygon.csv`：

```
t_s, n_pts, n_outer, area_ring1_m2, area_all_m2, alpha_max, x1, z1, x2, z2, ..., xN, zN
1.0, 120,   1,       0.573612,      0.573612,    0.007714, 4.34969, 0.17423, ...
0.5,   0,   0,       0.000000,      0.000000,    0.000000,   (空帧：不写坐标)
```

- 一帧一行 ⇒ **读一行 = 一次 `split(",")` = 一条闭合多边形**，零分组零排序；
- 顶点数**固定**（等弧长重采样到 120）+ **起点对齐**（取"从环心看角度最小"的顶点，
  外环已统一逆时针）⇒ 相邻帧可**逐点线性插值**，形状连续生长而不是跳变；
- `n_pts = 0` 表示该时刻还没有熔体落地 ⇒ 下游应隐藏多边形（前几帧常为空）；
- 只保留**最大外环**，所以必须并列写出 `area_ring1_m2` 与 `area_all_m2`，
  让下游自己看到"丢了哪一块、丢了多少"（L1 t=1.5 s 丢 18.4%）；
- **面积口径仍以 `shape.csv` 的 `area_face_m2` 为准**，宽表里的面积只是"这个文件画的形状"的面积。

**为什么不能只给栅格**：栅格是"区域内/外"的近似，边界呈阶梯状、格子数量大、
且要把阈值写死在栅格化那一刻；而多边形是**几何**，任意渲染端都能直接填充/裁剪/做点包含判定。

## 7.1 ⚠️ 但这份宽表**必须无 BOM**（`utf-8`，不是 `utf-8-sig`）

`utf-8-sig` 会在文件头写 `EF BB BF`。下游用 `split(",")` 解析时，
第一个字段变成 `"\ufefft_s"` / `"\ufeff1.0"`，`Double.parseDouble` 当场抛
`NumberFormatException`——**而且只在"第一个数"上报，看着像数据坏了**。

| 文件 | 编码 | 理由 |
|---|---|---|
| `<S>_splash_polygon.csv`（喂程序的） | **`utf-8`（无 BOM）** | 会被 `parseDouble` 逐字段解析 |
| 其余给人看/给 Excel 打开的中文 CSV | `utf-8-sig` | 中文 Excel 不乱码 |

## 7.2 ⚠️ 帧间起点必须**链式对齐**，否则插值会静默塌陷

"取从环心看角度最小的顶点当起点"这条规则**只保证同一帧内起点唯一，不保证帧间起点
落在同一物理位置**。等弧长重采样把顶点间距拉均匀后，起点漂移会变成"逐点配对错位"，
两个形状**各自都正常、逐点插值出来的中间帧却塌成一条细带**——不报任何错。

L1 实测（对齐前）：`t = 1.0 -> 1.5 s` 起点漂 **56/120** 个点，
中点（t=1.25 s）面积只有 **0.145 m2**，而两端是 **0.573 / 2.645 m2**。

**修法**：把后一帧**圆周移位**到与前一帧"顶点总位移最小"（全搜索 N 种移位，O(N²)，
N=120 时 14400 次比较，可忽略），并且**链式**传递（第 k 帧已对齐的版本当参考）。

| 对齐方式 | 1.0→1.5 中点面积 | 1.5→2.0 | 2.0→2.5 | 2.5→3.0 |
|---|---|---|---|---|
| 环心最小角度（原） | **0.145**（塌陷） | 0.509（塌陷） | 7.367 | 8.496 |
| 最小顶点位移（改） | 1.306 | 4.022 | 7.083 | 8.563 |

平均顶点位移同时从 1.51 / 1.64 / 1.85 / 1.96 m 降到 0.91 / 1.03 / 0.63 / 0.21 m。

## 7.3 插值**不保简单性** ⇒ 必须逐区间给"能不能插值"的判定

两端各自无自交，**中点仍可能自交**（L1：1.5→2.0 s 有 1 处、2.0→2.5 s 有 3 处），
填充渲染会出现蝴蝶结小瑕疵。所以导出时逐区间算两个量并给 `verdict`：

| 量 | 判据 |
|---|---|
| 中点插值面积 / min(两端面积) | ≥ 0.90 |
| 中点自交对数 | = 0 |
| 两个都满足 | `ok`（可插值），否则 `risky`（**直接切换帧**） |

L1 结论：4 个区间里 2 个 `ok`、2 个 `risky` ⇒ **默认建议按存档间隔直接切换，
不要插值**。要真正平滑的正路是**让 CFD 存密一点**（每 25 步 = 0.125 s），
而不是拿插值硬凑。

> 这套判定要落地成 `<S>_splash_polygon_check.csv`（逐区间）**和** JSON 里的 `lerp_check`，
> 让下游不必猜。

## 8.1 必须做的"回读校核"（做成可以跑的脚本，别只在脑子里过一遍）

导出后**只用主交付文件**、按下游的解析方式重建一次，再比对面积/形状。
本项目已固化为 `work/verify_polygon_csv.py <场景>`（纯离线、秒级），检查项：

| 检查 | 通过判据 |
|---|---|
| 文件是否带 BOM | **无**（有 BOM → 下游 `parseDouble` 在第一个数上炸） |
| 列数 = 6 + 2N、空帧数 | 与帧表一致 |

并输出 `results/<S>_轮廓坐标回读校核.png`：**上排实测帧、下排插值中点** ——

## 9. 换场景 / 阈值敏感性

```bash
python export_footprint_contours.py L1                    # 主口径 eps_core=0.02
python export_footprint_contours.py L1 --eps-core 0.015   # 更实心的形状
python export_footprint_contours.py L2 --fill-holes        # 下游不支持挖洞时
```

**交付时一定要附阈值敏感性表**（本例 t=3.0 s）：

| 阈值 | 0.03 | 0.02 | 0.015 | 0.01 |
|---|---|---|---|---|
| 面积 (m²) | 3.81 | 9.12 | 12.70 | 15.69 |
| 环数 | 4 | 1 | 2 | 1 |

单调降、无平台 ⇒ **数值扩散主导、网格依赖**，只能给量级与形态，
**不能**说成"液膜真实铺展面积"。这条必须与亚网格声明（见 `offline-h5-postprocessing.md` §8）
一起写进交付说明。
